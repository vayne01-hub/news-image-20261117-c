# news-image-20261117-c

One 1024×1024 PNG summarising the world's news of 17 November 2026: an editorial
infographic with a dotted world map, seven numbered story pins, and a short fact
line per story. The image is drawn entirely from code — a small PNG encoder, a
5×7 bitmap font, and hand-drawn map dots, pins and icons. No image assets are
embedded.
